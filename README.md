造物主创造了宇宙，地球所有权归造物主，管理神被造物主命令管理地球，地球轮回寿命未尽，神不允许彻底毁灭，所有生命灭绝。<br>

地球当下处于生死路口<br>

1.死，地球死期未到，全面核大战、或未来恐怖技术和武器，随意使用，全面使用，致星球彻底毁灭，神不允许，定会介入，且给予恐怖或至死的惩罚。但分几阶段介入，终极介入的时机，是个严肃问题。各国需谨慎，要对地球负责，对本国负责。<br>

2.生，战争和对抗是地球史的全过程，不可避免；战争情况，符合管理神的介入法时，管理神才会介入。<br>
◎地球死期未到，战争必须可控，即地球不能被恐怖武器彻底毁灭。<br>
◎战争只靠普通武器，也就意味着，对国家军事科技，和综合实力要求很高。<br>
◎国家要生存，就必须强力发展，激活社会创造力，形成军事科技、综合实力多元化有效平衡。<br>
◎所以，多数情况，国家要不自我改革，要不被敌人改革。

<h3>Note</h3>

缓冲期后，有国家政府治理能力低下，导致国家出现动荡<br>

1.形成少量公民，抗议政府的情形，成员洲官员介入调查，和协调各方，督促政府和抗议民众代表协商解决；<br>

2.形成大量公民，抗议政府的情形，成员洲官员介入调查，和协调各方，督促政府和抗议民众代表协商解决。努力后无法协商解决的，由成员洲官员，向地球联邦提交介入议案，成员洲代表、抗议民众代表、成员国政府代表，在地球联邦国会辩论，协商解决方案，后经地球联邦国会，决议通过后生效；<br>

3.形成大量公民，和政府武力对抗的情形，地球联邦派出治安力量，强制实施治安管制，对政府和抗议民众违法情况司法立案调查，对违法者实施抓捕。成员洲代表、抗议民众代表、成员国政府代表，在地球联邦国会辩论，协商解决方案，后经地球联邦国会，决议通过后生效；<br>

4.特别情况，如发生大量公民死伤，等满足地球联邦特别介入法案的情形，地球联邦派出武装力量和治安力量，强制实施军事和治安管制，对政府和抗议民众违法情况司法立案调查，对违法者实施抓捕。成员洲代表、抗议民众代表、成员国政府代表，在地球联邦国会辩论，协商解决方案，后经地球联邦国会，决议通过后生效；
